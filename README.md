# 웨딩홀 후기 노트

공유 후기 페이지(Claude 아티팩트): https://claude.ai/artifact/2MzW8zExYiCWZi8Cgv7ur1

예식장 후기를 작성하고 모아보는 단일 HTML 페이지입니다.

- 예식장 정보, 항목별 별점, 식대, 태그, 본문, 사진(최대 4장)
- 등록한 후기는 목록과 평균 별점·평균 식대 요약에 반영됩니다.
- 이 저장소의 `index.html`을 그대로 열면 후기가 해당 브라우저의 localStorage에만 저장됩니다.
- Claude 아티팩트로 게시하면 공유 저장소(db)에 저장되어 방문자 모두에게 실시간으로 보입니다.
